# Playwright Automation Framework (TypeScript & POM)

Framework de pruebas automatizadas End-to-End (E2E) desarrollado con **Playwright**, **TypeScript** y el patrón de diseño **Page Object Model (POM)** para la plataforma SauceDemo.

## 🚀 Características Técnicas
- **Page Object Model (POM):** Separación de la lógica de negocio de las páginas y los escenarios de prueba.
- **Autenticación por Estado (`storageState`):** Optimización de tiempos de ejecución reutilizando sesiones guardadas.
- **Data-Driven Testing (DDT):** Pruebas parametrizadas leyendo datos desde archivos externos (`.json`).

## 🛠️ Tecnologías
- TypeScript
- Playwright Test
- Node.js
